## How to use the CUDASCII Python module

1. Navigate to the build system artefact folder (i.e. `/build/debug/libraries/cudascii`)

2. Enter Python terminal (`python3`)

3. Type Python commands:

```python
import cudascii as ca
print(ca.image_to_ascii("/build/applications/sample/assets/isocpp_squished.png", 8, 14))
```
